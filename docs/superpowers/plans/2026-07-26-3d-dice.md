# 3D Dice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the die's 2D slot-machine reel with a real 3D solid whose shape is inferred from its face count, rolled by a hand-rolled physics simulation, landing on the server-decided value — without leaving the WAAPI animation architecture the parity harness protects.

**Architecture:** A physics sim authors a trajectory; it is expressed as a *curve function of progress*, compiled by a new motion-track form into WAAPI keyframes, and played on the die's `visual` channel. Outcomes are set by relabeling which face carries which value, never by re-rolling. Shape and face content are inferred from state.

**Tech Stack:** Lit 3, TypeScript, WAAPI, CSS 3D transforms, node:test, Playwright.

## Task 2: Per-track timing, easing pin, and gated declaration

**Files:**
- Modify: `server/static/src/components/boardgame-animatable-item.ts`
- Test: `server/static/tests/animations/curve-tracks.spec.ts` (new)

**Interfaces — Consumes:** `componentMotionTrackEasing`, `ComponentMotionTrack.samples/timeline/resting` from Task 1.

Three changes, all forced by the hazard review:

1. **Per-track timing.** `playMotionTracks` currently passes one `timing` to every track (`:198-204`). Derive per binding: if `componentMotionTrackEasing(track)` returns `'linear'`, pass `{...timing, easing: 'linear'}`; and **throw** if the caller supplied `timing.easing` for a sampled channel (two time warps on one channel is the same class of error as two owners).
2. **Resting write.** After starting each animation, if `track.resting !== undefined`, write it to the resolved target (`style.transform` or `style.opacity`). This makes reduced-motion correctness structural.
3. **Declare every gated play.** `will-animate` fires only on the 0→1 gated transition (`:311-326`); with per-track durations and `visualTracks` ordered last, the watchdog would arm from the short host FLIP. Dispatch on every gated play — `AnimationGate.willAnimate` is idempotent and monotone (`animation-gate.ts:110-118`) — or have `playMotionTracks` declare the batch max up front. Prefer the former; it is the smaller change and fixes the general case.

```ts
export interface DieFace { readonly normal: Vec3; readonly centroid: Vec3; readonly polygon: readonly Vec3[] }
export interface DieGeometry {
  readonly faceCount: number;
  readonly vertices: readonly Vec3[];
```

## Task 6: Rigid-body simulation

**Files:** Create `server/static/src/motion/dice-sim.ts` + `.test.ts`

**Interfaces — Produces:**

```ts
export interface RollConfig {
  readonly seed: number; readonly geometry: DieGeometry; readonly dieCount: number;
  readonly bounds: { readonly x: number; readonly y: number; readonly z: number };
  readonly energy?: number; readonly gravity?: number;
  readonly restitution?: number; readonly friction?: number;
}

  readonly samples: readonly { readonly t: number; readonly position: Vec3; readonly orientation: Quat }[];

```

Fixed timestep, vertex-based contact against the container planes (shape-agnostic — never special-case box faces), impulse response with restitution and friction, angular velocity through the inertia tensor, damping to rest.
